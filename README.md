# booktest — PDF(·로컬 전용 .mov)에서 글자를 뽑아 '책 PDF' 만들기

입력 PDF(또는 가정용 PC에서만: 아이폰 `.mov` 영상)를 페이지 이미지로 만들고, **Gemini**로 글자·표·그림 위치를 읽어
`output/책.pdf`(표지·목차·본문)를 만듭니다. 정확도가 완벽하지 않아도 책 PDF가 나오게 하고, 의심스러운 페이지는 리포트로 알려 줍니다.

## 확정된 설계 결정 (되돌리지 말 것)
- PDF 생성은 **xhtml2pdf + NanumGothic**(`bookpdf/fonts/`에 번들, OFL 라이선스). WeasyPrint는 쓰지 않음(Windows GTK 문제).
- OCR은 Claude API가 아니라 **Gemini**(무료/구독 티어). 키는 `.env`로만 받고 커밋하지 않음.
- 영상(.mov) 처리는 `bookpdf/local/` 에 분리된 **로컬 전용** 모듈. 영상 파일은 `.gitignore` 처리.

## 설치
```bash
pip install -r requirements.txt
# (가정용 PC에서 영상도 쓸 때만) pip install -r requirements-video.txt  + ffmpeg 설치(PATH)
cp .env.example .env      # GEMINI_API_KEY 를 채우기 (.env 는 커밋 금지)
```

## 사용
```bash
python -m bookpdf 입력.pdf                       # → output/책.pdf, output/전체원문.md, output/pages_md/, output/리포트.md
python -m bookpdf 입력.pdf --skip-ocr-if-text    # 텍스트 레이어가 있는 쪽은 OCR 생략(키 없이도 동작)
python -m bookpdf 책영상.mov --fps 3             # [로컬 전용] 영상 → 페이지 추출 → 펼침면 분리 → OCR → 책 PDF
python -m bookpdf 입력.pdf --max-pages 3         # 앞 3쪽만 시험
```
주요 옵션: `--out`, `--work`, `--name`(기본 `책.pdf`), `--title`, `--dpi`, `--threshold`(신뢰도 기준 0.7)

| 옵션 | 설명 |
|---|---|
| `--spread auto\|on\|off` | 펼침면(좌/우 두 쪽이 한 장) 분리. auto=가로세로비+제본선 자동 판별(기본) |
| `--gutter-offset 0.02` | 제본선 위치 수동 보정(이미지 폭 비율, +는 오른쪽) |
| `--spread-overlap 0.015` | 분리 시 안쪽으로 겹쳐 자르는 폭(글자 잘림 방지) |
| `--fps`, `--page-thr`, `--max-frame-side` | [영상] 초당 프레임, 페이지 구분 민감도, 프레임 긴 변 상한 |
| `--max-calls N` / 환경변수 `GEMINI_RPD` | 이번 실행/하루 Gemini 호출 상한. 도달하면 저장하고 멈춤 |
| `--allow-partial` | 중단돼 미처리 쪽이 남아도 처리된 쪽만으로 책 PDF 생성 |
| `--restart` | 이전 중간 결과를 지우고 처음부터 |

**모바일용 가정용 PC 실행 가이드: [`docs/가정용PC_실행가이드.md`](docs/가정용PC_실행가이드.md)**

**중단 후 이어서 실행**: 같은 `--out`(또는 `--work`)로 다시 실행하면 `work/pages/pNNNN.json` 이 있는 쪽은 건너뜁니다.
실패한 쪽·키가 없어 건너뛴 쪽은 저장하지 않으므로 다음 실행에서 다시 처리됩니다.
같은 영상·설정이면 영상 분석도 다시 하지 않습니다. 설정(`--spread`, `--fps` 등)이 달라지면 이전 결과와 섞이지 않도록 **멈추고** `--restart` 를 안내합니다.

**Gemini 호출 제한**: 분당 한도(429)는 서버가 알려준 시간만큼 기다린 뒤 재시도하고 `GEMINI_RPM` 으로 간격도 둡니다.
**하루 한도**(`PerDay` 등)는 기다려도 풀리지 않으므로 재시도하지 않고 저장 후 멈춥니다 → 다음 날 같은 명령으로 이어서 처리.
진행 중에는 `[57/400] … 쪽당 평균 6.1초, 남은 343쪽 약 35분(예상)` 처럼 진행률과 예상 시간을 표시합니다.

## 처리 순서
1. **입력 검증**: 파일 존재/암호/페이지 수(PDF), ffprobe 스트림·회전(영상).
2. **페이지 이미지화**: PDF → PyMuPDF 렌더. 영상 → ffmpeg(HEVC 디코딩, 회전 메타데이터 반영) 프레임을 **파이프로 한 장씩 스트리밍**
   → 흐린 프레임 제거(Laplacian 분산) → 정지 구간 묶기 → 페이지 넘김 감지 → 페이지당 가장 선명한 1장만 디스크 저장
   (전체 프레임을 쌓지 않아 300~400쪽 분량도 메모리·디스크 부담이 작음).
   페이지 구분은 카메라 평행이동을 위상상관으로 맞춘 뒤 **글자(잉크) 픽셀 겹침**으로 판단(평균 밝기 비교는 글자 페이지끼리 구분 못 함).
2b. **펼침면 분리**(PDF·영상 공통): 가로세로비 ≥1.25 이고 가운데 대역에 제본선(글자 없는 띠/제본 그림자)이 있으면 좌→우 두 쪽으로 분리.
   제본선을 위·중간·아래 3구간에서 따로 찾아 기울거나 휜 책도 글자가 잘리지 않게 겹쳐 자름. 단일 쪽 이미지는 그대로 통과.
3. **OCR**: Gemini에 이미지를 보내 Markdown(표는 Markdown 표) + 그림/도표 `box_2d` 를 받아, 좌표로 원본에서 그림을 잘라 저장.
4. **후처리**: 반복 머리글·쪽번호 제거, 겹친 인접 페이지 중복 문단 제거, 줄바꿈·하이픈 정리, 쪽 경계에서 끊긴 문단 병합.
5. **책 PDF**: Markdown → HTML → xhtml2pdf(NanumGothic). 표지·목차·본문(표·그림 포함).
6. **결과 검증**: 생성된 PDF를 다시 열어 글자·그림·NanumGothic 포함 여부 확인, `리포트.md` 에 신뢰도 낮은 쪽 목록과
   **쪽번호 점검**(인쇄된 쪽번호의 누락·중복·역행 의심 구간. 번호가 없는 쪽은 건너뛰고 앞뒤 번호로만 비교).

## 검증 상태 (2026-10-26, 이 저장소의 테스트 기준)
| 항목 | 상태 |
|---|---|
| PDF 입력 → 책 PDF (텍스트 레이어 경로, 표·그림·목차·한글 폰트) | 합성 한국어 샘플로 **검증** |
| Gemini 경로(JSON 파싱, 429/일일한도, 형식오류 재시도, 실패쪽 재개, 그림 크롭, 쪽번호) | **가짜 클라이언트로만** 검증. 실제 Gemini 호출은 **미검증**(이 세션에 키 없음) |
| 기본 모델 `gemini-2.5-flash` | 공식 문서로 **확정하지 못함**. `GEMINI_MODEL` 로 교체 |
| 펼침면 분리 (합성 펼침면 + 그림자/기울기±3°/휨/좁은 여백) | 합성 이미지로 **검증**: 좌→우 순서, 표식 잘림 0%. 실제 책 사진은 **미검증** |
| `.mov` 영상 (H.264/HEVC, 회전 메타 90°, 흐림·손떨림·넘김 전환, 펼침면 영상) | **합성 영상**으로만 검증. 실제 아이폰 영상은 **미검증** |
| 긴 영상(30쪽 합성, 쪽당 1초) 스트리밍 | 30/30쪽 검출, 순서 일치. **300~400쪽 실제 영상은 미검증** |
| 대형 책 PDF 조립(xhtml2pdf) | 합성 본문 실측(Linux): PDF 205쪽·그림 40개 2.9초/201MB, PDF 797쪽·그림 160개 12.5초/251MB |
| Windows/macOS 에서의 실행 | **미검증**(Linux 에서만 실행). 폰트는 번들되어 GTK 의존 없음 |

## 알려진 한계
- 영상: 쪽을 매우 빨리 넘기면(쪽당 1초 미만) 누락될 수 있음 → `--fps 5`. 같은 페이지가 쪼개지면 `--page-thr` 를 올리고, 다른 페이지가 합쳐지면 내리세요.
  전환 중 선명한 프레임이 1장 잡히면 가짜 쪽이 생길 수 있으나(실제 영상 미검증) 쪽번호 점검 리포트에서 중복 의심으로 드러납니다.
- 펼침면: 세로 직선으로 자르므로 제본선이 심하게 휘거나 기울면 **글자가 잘리는 대신 반대쪽 가장자리가 최대 절반 가량 섞일 수 있음**(합성 극단 조합 실측).
  겹침(`--spread-overlap`)은 합성 데이터에서는 필요성이 입증되지 않았고, 실제 사진(렌즈 왜곡·휜 글줄) 대비 안전 여백입니다.
  책 가장자리 밖 배경(책상 등)이 많이 찍힌 프레임은 자르기(크롭) 기능이 없어 OCR 품질이 떨어질 수 있음. 회전 보정(deskew)은 하지 않음.
- 쪽번호 점검은 Gemini가 번호를 읽어야 동작(번호 없는 책은 생략). 로마숫자 쪽번호는 무시.
- 목차에 쪽번호는 없음(제목 목록 + PDF 책갈피).
- 그림 크기는 원본에서 차지하던 폭 비율로 정해짐. 캡션은 Gemini가 준 경우에만 표시.
- xhtml2pdf 0.2.28 은 로컬 파일 읽기를 폴더로 제한하므로, 폰트·작업 폴더만 명시적으로 허용함(제한 해제 안 함).
